# LFM3 iOS SDK

This package provides the iPhone arm64 SDK used by the iOS demo. It contains static libraries, C++ headers, a relocatable CMake package, and third-party license notices. Models are distributed separately.

- Package: `zetic-lfm3-ios-arm64.tar.gz`
- SHA-256: `efd74dba409ad86b2fad630403eb41988d2936620b0bc1b8b05e25878754e6e0`
- Platform: iPhone arm64; SDK deployment target iOS 16 or later
- CMake package: `lib/cmake/LFM3IOS/LFM3IOSConfig.cmake`

The demo automatically checks and extracts the SDK when building. See the [iOS demo instructions](../demo-ios/README.md) for model access, downloading, and running on an iPhone. Retain the included third-party license notices when distributing the SDK.
